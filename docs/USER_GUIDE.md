# 用户指南

**最后更新**: 2026-03-08

这篇文档面向使用者，重点说明如何安装、采集、编辑和导出内容。

## 安装

### 加载扩展

1. 打开浏览器扩展页：`chrome://extensions/`
2. 开启“开发者模式”
3. 点击“加载已解压的扩展程序”
4. 选择构建后的 `dist/` 目录

如果你是从源码运行，请先执行：

```bash
npm install
npm run dev
```

## 第一次使用

1. 点击扩展图标打开侧边栏
2. 首页会看到默认的 `Inbox` 收集箱
3. 你可以直接把网页内容拖进去，也可以先创建项目

## 创建项目

### Canvas 项目

适合收集后导出为 Obsidian Canvas。

1. 点击“+ 新建画板”
2. 输入名称
3. 保持默认类型创建即可

### Markdown 项目

适合直接写入本地 Markdown 文件。

1. 先授权一个本地文件夹
2. 点击“+ 新建画板”
3. 选择 `Markdown`
4. 输入名称后，系统会在该文件夹中创建一个 `.md` 文件

## 采集内容

### 方式 1：拖拽

支持以下内容：

| 内容 | 操作方式 |
|------|----------|
| 文本 | 选中文字后拖入侧边栏 |
| 图片 | 直接拖拽网页图片 |
| 链接 | 拖拽链接本身 |

拖拽到首页时，内容会进入 `Inbox`；拖拽到项目页时，内容会进入当前项目。

### 方式 2：粘贴

在侧边栏中按 `Ctrl+V` / `Cmd+V`，支持：

- 文本
- 图片
- URL

系统会自动判断内容类型并创建对应卡片。

## 管理卡片

### 查看

- Canvas 项目以垂直列表展示卡片
- 文本、图片、链接会以不同卡片样式显示

### 编辑文本

- 双击文本卡片进入编辑
- `Shift + Enter` 保存
- 普通 `Enter` 用于换行
- 支持复制文本
- 如果文本被编辑过，可以在原始版和编辑版之间切换

### 删除与撤销

- 删除卡片后，会出现短暂的撤销提示
- 你也可以使用 `Ctrl+Z` / `Cmd+Z` 撤销最近一次删除

## 导出到 Obsidian

### 导出步骤

1. 进入一个 Canvas 项目
2. 点击顶部“导出”
3. 浏览器会下载一个 ZIP 文件

ZIP 内通常包含：

```text
[项目名].zip
├─ [项目名].canvas
└─ attachments/
```

### 导入到 Obsidian

1. 解压 ZIP
2. 把 `.canvas` 和 `attachments/` 放进同一个 Vault
3. 在 Obsidian 中打开 `.canvas`

## 本地 Markdown 模式

- 侧边栏中直接编辑本地 `.md` 文件
- 编辑器会自动保存
- 拖拽文本和链接可以直接插入 Markdown 项目
- 图片插入已经接入，但本地图片显示体验仍在持续优化

## 常见问题

### 侧边栏打不开

- 刷新扩展后重试
- 确认浏览器支持 Side Panel

### 拖拽后没有生成内容

- 先刷新当前网页
- 再重试拖拽
- 某些网站对拖拽有额外限制，属于已知兼容性问题

### 图片没有成功加入

- 目标站点可能限制图片拉取
- 可以稍后重试，或直接拖拽本地图片文件

### 数据会不会丢

- 正常关闭浏览器、重启电脑通常不会丢失
- 卸载扩展可能会清空本地数据
- 重要内容建议及时导出备份

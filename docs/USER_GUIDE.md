## 快速开始

### 第一步：加载扩展

#### 开发者模式安装

1. 打开 Chrome 或 Edge 浏览器
2. 访问 `chrome://extensions/`
3. 开启右上角 **"开发者模式"**
4. 点击 **"加载已解压的扩展程序"**
5. 选择项目的 `dist` 目录
6. 扩展图标出现在工具栏

#### 构建生产版本

```bash
npm run build
```

然后加载 `dist/` 目录。

---

## 核心功能

### 1. 创建项目

1. 点击扩展图标打开侧边栏
2. 点击 **"+ 新建画板"**
3. 输入项目名称
4. 按 Enter 创建

### 2. 收集箱 (Inbox)

- **收集箱** 是默认的临时收集区
- 未进入项目时，内容直接保存到这里
- 绿色主题区分，带有"默认"标签
- 无法删除（保护机制）

## 内容采集

### 支持的内容类型

| 类型 | 采集方式 | 显示效果 |
|------|----------|----------|
| **文本** | 选中文字 → 拖拽 | 文本卡片 |
| **图片** | 拖拽图片 | 图片卡片（自动下载） |
| **链接** | 拖拽链接 | 链接卡片 |

### 方式 1：拖拽采集

1. 在任意网页选中文字或找到图片
2. 拖拽到侧边栏
3. 松开鼠标，卡片自动创建

**图片处理**：
- 自动后台下载（解决防盗链）
- 显示 Loading 骨架屏
- 下载完成后显示图片

### 方式 2：粘贴采集 (Ctrl+V)

1. 复制内容（文本/图片/URL）
2. 打开侧边栏
3. 按 `Ctrl+V`（Mac: `Cmd+V`）
4. 内容自动创建

**支持的粘贴类型**：
- 纯文本 → 文本卡片
- 剪贴板图片 → 图片卡片
- URL → 链接卡片（自动识别）

## 卡片管理

### 查看卡片

- 点击项目卡片进入详情页
- 所有卡片以垂直列表显示
- 按采集顺序排列

### 卡片类型

#### 文本卡片

- 最多显示 4 行（超出截断）
- 超过 300 字符显示"展开全部"
- 底部显示来源网站 Favicon + 域名

**编辑功能**：
- 双击卡片进入编辑
- 支持原始/编辑版本切换（四象限交互）
- 一键复制文本

#### 图片卡片

- 图片最大高度 180px
- 自动裁剪保持整齐
- 显示 Loading/Error 状态
- 底部显示来源网站

#### 链接卡片

- 显示 Favicon + 标题 + 域名
- 点击卡片跳转原链接

### 删除与撤销

1. 悬停卡片，点击右上角 **×** 删除
2. 卡片立即消失
3. 底部弹出 Toast："已删除 (撤销)"
4. 3 秒内点击 **撤销** 或按 `Ctrl+Z` 恢复

### 调整顺序

1. 拖拽卡片到目标位置
2. 松开鼠标完成排序

## 文本编辑（版本控制）

### 四象限交互

文本卡片支持四个隐藏按钮，双击卡片任意区域进入编辑：

| 位置 | 功能 | 说明 |
|------|------|------|
| 左上角 | 版本切换 | 原始版本 ↔ 编辑版本 |
| 右上角 | 复制 | 一键复制文本 |
| 左下角 | （空） | 双击进入编辑 |
| 右下角 | 删除 | 删除卡片 |

### 版本控制

- **第一次编辑**: 自动保存原始版本
- **后续编辑**: 只更新编辑版本
- **切换显示**: 点击左上角按钮切换

## 导出到 Obsidian

### 导出流程

1. 确保在项目详情页
2. 点击顶部 **"导出"** 按钮
3. 浏览器自动下载 `[项目名].zip`

### ZIP 文件内容

```
[项目名].zip
├── [项目名].canvas          # Obsidian Canvas 文件
└── attachments/              # 图片附件目录
    ├── image-xxx.png
    └── image-yyy.png
```

### 在 Obsidian 中使用

1. 打开 Obsidian（版本 1.0+）
2. 解压下载的 ZIP 文件
3. 将 `.canvas` 文件和 `attachments/` 文件夹放入 Vault
4. 在 Obsidian 中点击 `.canvas` 文件打开

**显示效果**：
- 所有卡片按 4 列网格自动排列
- 文本节点支持 Markdown
- 图片正常显示
- 链接节点可点击跳转

## 常见问题

### Side Panel 无法打开

**解决**：
1. 重新加载扩展（`chrome://extensions/` → 刷新）
2. 检查浏览器版本（需要 Chrome/Edge >= 120）

### 拖拽后没有创建卡片

**解决**：
1. 刷新网页（Content Script 需要重新注入）
2. 检查控制台错误（F12 → Console）

### 图片下载失败

**原因**：
- 图片服务器防盗链
- 网络连接问题

**解决**：
1. 等待几秒后重试
2. 直接拖拽本地图片文件

### 导出后 Obsidian 中图片不显示

**解决**：
1. 确保 ZIP 文件已完全解压
2. 检查 `attachments` 文件夹和 `.canvas` 文件在同一目录

### 导出的 Canvas 无法编辑（Advanced Canvas 插件）

**解决**：
1. 设置 → 社区插件 → Advanced Canvas
2. 禁用 "Protect external files" 选项
3. 或在 `.canvas` 文件添加 frontmatter：
   ```yaml
   ---
   created-by: Cascade
   source: internal
   ---
   ```

## 技术细节

### 数据存储

- **位置**: 浏览器 IndexedDB
- **库名**: `CascadeDB`
- **容量**: Chrome 约 5-10GB
- **特点**: 完全本地存储，关闭浏览器后数据仍在

### 数据安全

- ✅ 所有数据存储在本地
- ✅ 不会上传到任何服务器
- ✅ 导出后数据仍在扩展中（双向独立）

### 浏览器兼容性

| 浏览器 | 版本 | 状态 |
|--------|------|------|
| Chrome | >= 120 | ✅ |
| Edge | >= 120 | ✅ |
| Firefox | - | ❌ |
| Safari | - | ❌ |

## 调试与日志

### 查看日志

**Side Panel 日志**：
1. 右键 Side Panel → "检查"
2. Console 标签查看 `[Cascade]` 前缀日志

**Background Service Worker 日志**：
1. `chrome://extensions/`
2. 点击扩展卡片的 "service worker" 链接

**Content Script 日志**：
1. 任意网页按 F12
2. Console 查看 `[Cascade]` 日志

### 常见日志

```
[Cascade] Exporting project: 项目名
[Cascade] Text node added successfully
[Cascade] Image downloaded: image-xxx.png
[Cascade] Export completed: 项目名
```

## 卸载

### 移除扩展

1. 访问 `chrome://extensions/`
2. 找到 "Cascade" 扩展
3. 点击 **"移除"**

### 数据清理

- 卸载后 IndexedDB 数据会被浏览器自动清理
- 无需手动操作

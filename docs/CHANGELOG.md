# 更新日志 (CHANGELOG)

**项目**: Cascade (原名 WebCanvas)

---

## [1.0.0] - 2026-02-20

### 🎉 正式发布

#### 核心功能

**项目管理**
- ✅ 创建、删除、重命名项目
- ✅ Inbox 收集箱（默认收集区）
- ✅ 项目类型支持（Canvas / Markdown）

**内容采集**
- ✅ 拖拽文本（选中网页文字）
- ✅ 拖拽图片（自动后台下载）
- ✅ 拖拽链接（自动提取信息）
- ✅ 拖拽本地图片文件
- ✅ 粘贴文本/图片/URL（Ctrl+V）

**卡片管理**
- ✅ 垂直列表布局
- ✅ 拖拽排序（@dnd-kit）
- ✅ 删除卡片
- ✅ 撤销删除（Ctrl+Z）

**文本编辑**
- ✅ 双击进入编辑
- ✅ 版本控制（原始/编辑版本）
- ✅ 一键复制
- ✅ 四象限交互设计

**导出功能**
- ✅ 导出到 Obsidian Canvas
- ✅ 4 列网格布局算法
- ✅ 图片打包（attachments 文件夹）
- ✅ 行结尾标准化（Windows → Unix）
- ✅ Link 节点规范（只有 url 字段）

**本地 Markdown**
- ✅ Markdown 项目类型
- ✅ 本地文件编辑（File System Access API）
- ✅ 文件句柄存储

### 🐛 Bug 修复

- 修复图片下载 CORS 问题（使用 Background 代理）
- 修复拖拽 payload 丢失问题（Background 缓存）
- 修复数据库版本迁移问题（v1 → v2 → v3）
- 修复导出 JSON 包含 `\r` 字符问题

### 📦 技术栈

| 构建 | Vite 7 + CRXJS 2.3 |
| 数据库 | Dexie.js 4.2 |

## [0.x.x] - 2026-01-14 ~ 2026-02-19

### 历史版本（WebCanvas 时期）

**功能**
- 基础的拖拽采集功能
- 简单的列表展示
- 导出到 Obsidian

**技术**
- 使用 `WebCanvasDB` 数据库
- 无版本控制
- 无 Undo 功能
- 无本地 Markdown 支持

**更名说明**

2026-02-20 正式更名为 **Cascade**，原因：
- 更简洁易记
- 避免与 "Web Canvas" 混淆
- 体现"级联"的数据流理念

## 版本说明

### 版本号规则

采用语义化版本号：`主版本。次版本.补丁版本`

- **主版本**: 架构变更或不兼容更新
- **次版本**: 新功能添加
- **补丁版本**: Bug 修复和小优化

### 发布周期

| 类型 | 周期 | 内容 |
|------|------|------|
| 主版本 | 不定期 | 重大变更 |
| 次版本 | 月度 | 新功能 |
| 补丁版本 | 周度 | Bug 修复 |

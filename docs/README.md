### 2. 架构说明

- 适合开发、排查和理解系统边界

### 3. 用户指南

- `USER_GUIDE.md`
- 适合演示、使用和写操作手册

### 4. 参考手册

- `REFERENCE.md`
- 适合开发者和维护者
- 合并了功能现状、数据库结构、导出规则和关键限制

### 5. 路线图

- `ROADMAP.md`
- 适合维护者和后续迭代

## 推荐阅读路径

| 快速了解项目 | `../README.md` → `ARCHITECTURE.md` → `REFERENCE.md` |

## 文档原则

- 以当前代码为准，不保留历史幻觉
- 每篇文档只回答一类问题
- 优先保留高价值事实、流程和限制
- 尽量少解释，尽量少重复

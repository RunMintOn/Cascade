# 故障排查指南

**版本**: 2.0  
**最后更新**: 2026-01-18

---

## 快速诊断流程

```
问题发生
    ↓
1. 查看 Console 日志 (F12)
    ↓
2. 定位错误类型
    ↓
3. 查找对应解决方案
    ↓
4. 验证修复
```

---

## 常见问题

### 1. Side Panel 无法打开

**症状**：点击扩展图标无反应

**可能原因**：
- 扩展未正确加载
- 浏览器版本不支持

**解决方案**：
1. 访问 `chrome://extensions/`
2. 找到 WebCanvas 扩展
3. 点击刷新按钮重新加载
4. 检查浏览器版本（需要 >= 120）

---

### 2. 拖拽后没有创建卡片

**症状**：拖拽内容到侧边栏后无任何反应

**可能原因**：
- Content Script 未注入
- 网页刷新后才能生效

**解决方案**：
1. 刷新网页（F5）
2. 重新尝试拖拽
3. 查看 Console 是否有 `[WebCanvas]` 日志

**调试步骤**：
```javascript
// 在网页 Console 中检查
console.log('Content Script loaded?')
// 应该看到 [WebCanvas] 相关日志
```

---

### 3. 图片下载失败

**症状**：图片卡片显示"加载失败"

**可能原因**：
- 图片服务器防盗链
- CORS 跨域问题
- 网络连接问题

**解决方案**：
1. 等待几秒后重试（后台自动重试）
2. 直接拖拽本地图片文件
3. 检查 Background Service Worker 日志

**查看 Background 日志**：
1. `chrome://extensions/`
2. 点击 WebCanvas 卡片的 "service worker" 链接
3. 查看错误信息

---

### 4. 粘贴功能不工作

**症状**：按 Ctrl+V 后无反应

**可能原因**：
- 剪贴板为空
- 事件未正确监听

**解决方案**：
1. 确认已复制内容（文本/图片）
2. 查看 Console 日志：`[WebCanvas] Paste event triggered`
3. 检查是否有 JavaScript 错误

**支持的粘贴类型**：
- ✅ 纯文本
- ✅ 剪贴板图片
- ✅ URL 链接
- ✅ HTML 内容

---

### 5. 导出后 Obsidian 中图片不显示

**症状**：在 Obsidian 中打开 Canvas，图片显示为裂图

**可能原因**：
- ZIP 未正确解压
- 文件路径错误

**解决方案**：
1. 确认 ZIP 已完全解压
2. 检查目录结构：
   ```
   project/
   ├── project.canvas
   └── attachments/
       └── image.png
   ```
3. 确保 `.canvas` 和 `attachments/` 在同一级目录

---

### 6. 导出的 Canvas 无法编辑（Advanced Canvas）

**症状**：在 Obsidian 中打开 Canvas 后无法编辑节点

**原因**：Advanced Canvas 插件对外部文件应用只读保护

**解决方案 A**：禁用保护
1. Obsidian 设置 → 社区插件 → Advanced Canvas
2. 禁用 "Protect external files" 或类似选项
3. 重启 Obsidian

**解决方案 B**：添加 frontmatter
1. 用文本编辑器打开 `.canvas` 文件
2. 在文件开头添加：
   ```yaml
   ---
   created-by: Obsidian
   source: internal
   editable: true
   ---
   ```
3. 保存后重新打开

**解决方案 C**：临时绕过
1. 关闭 Advanced Canvas 插件
2. 打开 Canvas 文件
3. 按 Ctrl+S 保存
4. 重新启用 Advanced Canvas

---

### 7. IndexedDB 配额警告

**症状**：无法添加新卡片，提示存储已满

**可能原因**：达到浏览器存储配额

**解决方案**：
1. 删除不用的项目释放空间
2. 清理浏览器数据：
   - `chrome://settings/siteData`
   - 搜索 "webcanvas" 或 localhost
   - 删除相关数据

**配额限制参考**：
| 浏览器 | 配额 |
|--------|------|
| Chrome | ~5-10GB |
| Edge | ~5-10GB |
| Firefox | ~2GB |
| Safari | ~1GB |

---

### 8. Service Worker 连接错误

**症状**：Console 显示
```
Error: Could not establish connection. Receiving end does not exist.
```

**可能原因**：
- Service Worker 未正确注册
- Vite/CRXJS 配置问题

**解决方案**：
1. 重新加载扩展
2. 检查 `manifest.config.ts` 配置
3. 检查 `vite.config.ts` 中 service worker 配置
4. 临时方案：在 `chrome://extensions/` 中重启 Service Worker

---

### 9. 导出功能无响应

**症状**：点击导出按钮后无下载

**可能原因**：
- 项目为空
- JSZip 库未正确加载

**解决方案**：
1. 确认项目中有卡片
2. 查看 Console 错误
3. 检查是否有 `[WebCanvas] Export completed` 日志

---

### 10. 卡片排序异常

**症状**：拖拽排序后位置错乱

**可能原因**：
- `order` 值计算错误
- 数据库更新失败

**解决方案**：
1. 刷新页面重新加载
2. 检查 Console 是否有数据库错误
3. 手动调整顺序触发重新计算

## 调试工具

### 查看日志

**Side Panel 日志**：
1. 右键 Side Panel → "检查"
2. Console 标签

**Background 日志**：
1. `chrome://extensions/`
2. 点击 "service worker" 链接

**Content Script 日志**：
1. 网页按 F12
2. Console 标签

### 常用日志过滤

在 Console 中过滤 `[WebCanvas]`：
```
[WebCanvas] Paste event triggered
[WebCanvas] Pasted text: ...
[WebCanvas] Pasted image: ...
[WebCanvas] Download failed: ...
[WebCanvas] Export completed: ...
```

### 数据库检查

在 Console 中检查数据库内容：
```javascript
// 查看所有项目
db.projects.toArray().then(console.log)

// 查看某个项目的所有卡片
db.nodes.where('projectId').equals('project-id').toArray().then(console.log)
```

## 错误代码速查

| 错误信息 | 原因 | 解决方案 |
|----------|------|----------|
| `QuotaExceededError` | 存储已满 | 删除旧项目 |
| `NetworkError` | 图片下载失败 | 检查网络/防盗链 |
| `DataCloneError` | 尝试索引 Blob | 检查 db.ts schema |
| `TypeError: Cannot read property` | 数据为空 | 检查数据是否存在 |

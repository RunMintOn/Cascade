## 1. TypeScript 类型定义

### 1.1 核心接口

```typescript
// src/shared/types.ts

/**
 * 画板/项目
 */
export interface Project {
  id: string;          // UUID
  name: string;        // 画板名称
  createdAt: number;   // 创建时间戳
  updatedAt: number;   // 最后更新时间戳
  isInbox?: boolean;   // 是否为默认收集箱
}

/**
 * 卡片节点
 */
export interface CanvasNode {
  id: string;          // UUID (对应 Obsidian Node ID)
  projectId: string;   // 所属画板 ID
  type: NodeType;
  order: number;       // 排序索引 (整数)

  // 内容载荷 (根据 type 不同而不同)
  text?: string;       // 文本内容 / 链接 Title
  fileData?: Blob;     // 图片二进制 (IndexedDB 独有，不索引)
  fileName?: string;   // 文件名 (e.g., "image-1737123456.png")
  url?: string;        // 链接 URL

  // 来源元数据
  sourceUrl?: string;  // 来源网页 URL
  sourceIcon?: string; // 来源 Favicon URL
  
  createdAt: number;
}

export type NodeType = 'text' | 'file' | 'link';

/**
 * 拖拽数据包 (从网页传递到侧边栏)
 */
export interface DragPayload {
  sourceUrl: string;
  sourceTitle: string;
  type: 'text' | 'image' | 'link' | 'unknown';
  content: string | null;
  src?: string;        // 图片 URL
  href?: string;       // 链接 URL
  text?: string;       // 链接文本
}
```

```typescript
  fromNode: string;
  toNode: string;

}
```

## 2. IndexedDB Schema (Dexie)

### 2.1 数据库定义

```typescript
// src/sidepanel/services/db.ts

import Dexie, { Table } from 'dexie';

class WebCanvasDB extends Dexie {
  projects!: Table<Project, string>;  // id 为主键
  nodes!: Table<CanvasNode, string>;  // id 为主键

  constructor() {
    super('WebCanvasDB');
    
    // Schema 定义
    this.version(2).stores({
      projects: 'id, name, updatedAt, isInbox',
      // ⚠️ 重要：fileData 字段不索引！
      // 对 Blob 创建索引会导致数据库崩溃
      nodes: 'id, projectId, type, order, createdAt'
    });
  }
}

export const db = new WebCanvasDB();
```

### 2.2 版本历史

| 版本 | 变更 |
|------|------|
| v1 | 初始版本：projects + nodes 表 |
| v2 | 新增 `isInbox` 字段到 projects |

### 2.3 索引策略

```typescript
// ✅ 正确索引
nodes: '++id, projectId, type, order, createdAt'

// ❌ 错误索引 - 不要索引 Blob 字段
nodes: '++id, projectId, fileData'  // 会崩溃！

// 查询示例
await db.nodes.where('projectId').equals(projectId).sortBy('order')
await db.nodes.where('type').equals('file').toArray()
```

## 3. 数据流转

```
网页拖拽/粘贴
    ↓
[DragPayload] 解析
    ↓
[CanvasNode] 创建
    ↓
```

## 4. 数据转换适配器

### 4.1 CanvasNode → ObsidianCanvasNode

```typescript
function toObsidianNode(node: CanvasNode, x: number, y: number): ObsidianCanvasNode {
  const base = {
    id: node.id,
    x: Math.round(x),
    y: Math.round(y),
    width: 400,
    height: estimateHeight(node.type)
  }

  switch (node.type) {
    case 'text':
      return {
        ...base,
        type: 'text',
        text: node.text || ''
      }
    
    case 'file':
      return {
        ...base,
        type: 'file',
        file: `attachments/${node.fileName}`
      }
    
    case 'link':
      // ⚠️ 注意：Link 节点只能有 url 字段，不能有 text 字段
      return {
        ...base,
        type: 'link',
        url: node.url || ''
      }
  }
}

function estimateHeight(type: NodeType): number {
  switch (type) {
    case 'text': return 200
    case 'file': return 300
    case 'link': return 150
  }
}
```

### 4.2 UUID 生成

```typescript
function generateUUID(): string {
  return 'xxxxxxxx-xxxx-4xxx-yxxx-xxxxxxxxxxxx'.replace(/[xy]/g, (c) => {
    const r = Math.random() * 16 | 0
    const v = c === 'x' ? r : (r & 0x3 | 0x8)
    return v.toString(16)
  })
}
```

## 5. 存储限制与最佳实践

### 5.1 IndexedDB 配额

| 浏览器 | 配额 | 说明 |
|--------|------|------|
| Chrome | ~5-10GB | 临时存储 + IndexedDB 共享 |
| Edge | ~5-10GB | 与 Chrome 相同 |
| Firefox | ~2GB | 相对严格 |
| Safari | ~1GB | 相对严格 |

### 5.2 典型数据大小

| 类型 | 大小估算 |
|------|----------|
| 文本节点 | ~500 字节 |
| 小图标 | ~1KB |
| 普通截图 | ~500KB |
| 高清照片 | ~5MB |

### 5.3 最佳实践

1. **Blob 不索引** - 避免数据库崩溃
2. **及时清理** - 删除不用的项目释放空间
3. **批量操作** - 使用 `db.transaction()` 保证原子性
4. **响应式更新** - 使用 `useLiveQuery` 自动同步 UI
